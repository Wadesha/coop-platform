# 丰禾农业合作社管理平台（前端原型）

面向农业专业合作社的运营管理后台原型。单文件 HTML，零构建，浏览器直接打开即可使用。

## 功能模块

| 模块 | 说明 |
|---|---|
| 仪表盘 | 核心 KPI（社员 / 面积 / 销售额 / 利润 / 库存预警）+ 月度销售趋势 + 作物面积分布 |
| 数据看板 | 县域 × 作物堆叠分布、收支结构、社员股权结构、库存余量预警 |
| 社员管理 | 社员名册、股权、角色、状态维护（增删改查） |
| 地块与种植 | 地块台账、作物、负责人、县域（增删改查） |
| 库存物资 | 农资库存与低于阈值的自动预警 |
| 农资采购 | 采购单与付款状态管理 |
| 销售订单 | 销售单与回款状态，金额按数量 × 单价自动计算 |
| 财务与分红 | 收支流水 + 按在职社员出资比例自动测算年度分红 |

## 技术栈

- 纯前端单文件：HTML + CSS + 原生 JavaScript
- [Chart.js](https://www.chartjs.org/)（CDN）用于可视化
- 业务数据存于浏览器 `localStorage`，刷新不丢失

## 本地运行

直接双击打开 `index.html`，或：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 数据口径

- 地理维度下沉到**县**（临沭县 / 莒南县 / 郯城县），不做宏观分区笼统分析。
- 分红测算：可分配盈余 = 销售收入 − 采购支出 − 20% 公积金，按在职社员出资比例分配。
- 内置示例数据，仅用于演示平台能力。
